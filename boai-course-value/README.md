# 博AI课程理念与验收

用于课前讨论和课后检查课程是否围绕客户需求、实操作品与岗位产出，交付价值观核对、证据缺口和可执行改进建议。

## 安装与使用

将完整目录交给Agent：“请安装 https://github.com/Captainf5/boai-course/tree/main/boai-course-value ，然后用它检查我的课程方向。”无需额外配置或API Key。

## 兼容性与依赖

需要能够发现SKILL.md并读取课程材料的Agent；无强制运行时依赖。不包含任何账号授权。

## 数据与适用边界

只评价材料可支持的设计与教学行为，不把满意度或讲师自述当成学习效果。客户原件留在使用者的项目中；外部模型处理材料遵守实际授权。本Skill不替代课纲、PPT制作与数据分析。

## 验证

关键判断应能回到课程需求、任务、学员作品或反馈；没有证据明确标记不足。历史使用记录不代表所有宿主都已实测。
