# 教学包装模板（任务卡 + 讲解稿 + 金句库）

## 实操任务卡模板（学生版最后一个sheet）

任务编号从0开始（基础技能前置），每个任务一句话说清"用什么表做什么"：

```
任务0 [率计算]   用[台账表]计算: ①单月率 ②项目全年率=Σ分子/Σ分母 ③区域及公司整体。禁止简单平均
任务1 [环比]     计算各项目每月环比增长率, 找出连续3个月以上环比下滑的项目
任务2 [同比]     关联[同期表], 计算各项目全年同比增长率并排序
任务3 [透视]     ①维度×月份透视 ②占比与排名 ③按季度汇总 ④切片器联动筛选
任务4 [异常]     检测2-3列异常点并解释原因, 区分单点异常与系统性超标
任务5 [下探]     公司→区域→项目逐层下探, 定位拖累整体的项目, 用率佐证严重程度
任务6 [盈亏平衡] 基于[参数表]: 临界值是多少? 安全垫多少?
任务7 [敏感性]   变量A±5% × 变量B±5pt 的利润敏感性矩阵
任务8 [情景]     悲观/基准/乐观三情景测算与经营建议
拓展 [蒙特卡洛]  (选做)关键变量加分布, 模拟10000次估计亏损概率
终极 [HTML报告]  综合以上分析, 生成带核心洞察的HTML报告(结论必须有数据支撑)
```

## 讲解稿结构（每个任务五件套）

```
任务N · 名称（用时）
meta: 用表 | 目标产出
【一步一步操作】  编号步骤, 软件点击路径 + AI Prompt 双轨
【预期答案】      脚本验证过的数字(老师巡场对答案用, 不投屏)
【讲解稿】        可直接念的台词, 含设问/停顿/反转
【坑与救场】      本任务的坑+正解+学员卡住怎么办
```

## 90分钟动线参考

| 环节 | 用时 | 要点 |
|---|---|---|
| 开场定身份 | 5' | "老板扔给你一张表问经营怎么样"——给身份给规则（全程AI, 你问它算） |
| 认识数据 | 10' | AI读表结构; 多表分离是常态 |
| 环比/同比 | 20' | 埋"整体平稳"的坑, 忍住不揭晓 |
| 透视+切片器 | 15' | 三要素提问法（维度/度量/聚合） |
| 异常检测 | 15' | 单点vs系统性; 异常不一定是坏事 |
| 下探分析 | 15' | 反转高潮: 平均数会说谎 |
| HTML报告 | 10' | 军规: 每个结论必须跟数据 |

下午财务预演场（如有）：参数表→盈亏平衡→敏感性→情景→蒙特卡洛，各15分钟。
开场三句话："明细表说过去，参数表说假设，模型表说未来。"

## 金句库（可投屏）

- 率不可求和，率不可乱平均；先加总，再相除
- 环比看拐点，同比看趋势；单看环比会被基数骗
- 平均数是会说谎的——整体结论只能安慰人，结构结论才能救公司
- 异常不一定是坏事；分析师的价值不是找到异常，是解释异常
- 单点异常用算法，系统问题看基线——一个是感冒发烧，一个是慢性病
- 排名挑字段，排序不挑字段
- 格式跟着存储值走，不跟着感觉走
- 明细表说过去，参数表说假设，模型表说未来
- 一个数字不如一个分布（蒙特卡洛）
- AI做执行，人做判断。执行成本趋近于零，判断的价值被无限放大
