# 教学坑全清单（讲解时用的弹药库）

## 数据坑（学员必踩，踩完再讲）

### 1. 文本月份排序
表现：1月排到10月后面（"2025-1" vs "2025-10"文本排序）。
正解：月份统一零填充文本（2025-01）；口诀"涉及时间，先查排序，再看数字"。

### 2. 率的三板斧（核心教学点）
| 坑 | 表现 | 正解 |
|---|---|---|
| 率求和 | 收缴率合计9381% | 率永远不求和 |
| 率乱平均 | 单月收缴率直接平均 | 加权：Σ实收/Σ应收，先加总再相除 |
| 格式×100 | 98.6显示成9864% | 数据存百分数选"数值"格式；存小数（0.986）才选"百分比"格式 |

口诀："格式跟着存储值走，不跟着感觉走。" 占比（透视算出来存0.436小数）选百分比格式；收缴率（源数据存98.6）选数值格式——两者对照讲。

### 3. 求和变计数
表现：透视表值区域全是1、2、3小整数。
正解：值字段设置→求和；口诀"数字不对劲，先查聚合方式"。

### 4. 辅助行混入
表现：同期表混入上一年12月辅助行，全年求和多算一个月。
正解：求和限定年份；这也是真实数据的常态，值得让学员自己发现。

### 5. AI计算坑
- 同比拿错分母（用上月当去年同期）→ Prompt写死匹配规则"2025-01对2024-01"
- 率直接简单平均 → Prompt写死"用Σ实收/Σ应收，不要用单月平均"
- 铁律：AI算完必须抽一行手验

## 工具坑（Excel/WPS 透视表）

### 6. 值显示方式地图
- **占比** → 总计的百分比（÷全表总计）；列/行汇总百分比=列内/行内占比；父行汇总=项目占所属区域
- **环比** → 差异百分比，基本字段=月份，基本项=（上一个）
- **同比** → 透视表做不了跨表！要么加"年份"辅助列+差异百分比（基本字段=年份，基本项=上一个），要么交给AI跨表算
- **基本项留空是对的**——排名不需要基本项（那是给差异类用的）

### 7. 排名翻车两连（WPS尤其不稳）
- 基本字段选错层（选区域）→ 项目行全是 #N/A
- 基本字段=区域时全是1 → 排名规则是"组内排名"，组里没对手人人第一
- 两级行字段下永远只能组内排名，给不了全局名次
- **正解：排名挑字段，排序不挑字段**——右键数值→排序→降序，教学用排序

### 8. 分类汇总/总计清理
- 分组小计（"北区汇总"）：设计→分类汇总→不显示分类汇总；或右键字段→字段设置→无
- 底部总计：设计→总计→对行和列禁用

### 9. 透视表勾稽
透视合计必须=明细合计（选中明细列看状态栏求和），对不上先查聚合方式。透视表第一定律。

## 讲解节奏技巧

1. 坑不要提前说破，让学员踩一次再讲——记忆最深
2. "整体平稳"反转：前面环节忍住，下探环节才揭晓
3. 教师亲踩坑是最佳素材："我昨晚备课也算出9864%"——自嘲式开场建立信任
4. 救场预案常备：工具卡壳切AI Prompt路径；快组加赛题（预测下月营收）；时间不够砍手工留高潮
