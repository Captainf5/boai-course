# 博AI增效数据案例 Skill

为AI数据分析课程设计实操案例的标准流程。核心信念：**案例的价值不在数据本身，而在埋进去的教学点——每个坑都是设计出来的，每个数字都必须验证。**

## 铁律（不可违反）

1. **数字必须跑脚本验证**：老师版所有参考答案由脚本从数据计算生成，禁止手写；生成后打印验证摘要（环比连跌月数、同比、z-score、勾稽差）
2. **率不预存**：明细表不给现成"率"字段，给分子分母（应收/实收），让学员自己算——正确算法 = Σ分子/Σ分母
3. **种子固定**：`random.seed(42)`，数据集可复现；改参数即可生成防泄题变体
4. **勾稽校准**：参数表必须与明细表一致（如 模型利润=明细利润，面积=营收/(单价×收缴率) 反推）
5. **双版本**：学生版=数据+任务卡（无答案）；老师版=同数据+埋点答案+指标速查+教学动线

## 五步法工作流

### 第1步 需求拆解

把教学目标翻译成数据需求，先建映射表：

| 要练的技能点 | 需要的数据特征 |
|---|---|
| 环比/同比 | 连续月份≥13个月 + 去年同期表（跨表关联） |
| 透视表/切片器 | ≥2个分类维度（区域/项目/业态）+ 1个时间维度（含季度衍生列） |
| 异常值检测 | 埋2-3个单点异常（z>2）+ 1个系统性超标（趋势病，算法抓不到） |
| 下探分析 | 层级维度（公司→区域→项目）+ 结构分化（整体平稳掩盖两极） |
| 财务建模（敏感性/情景/盈亏平衡/蒙特卡洛） | 参数表：单价/面积/变动成本率/固定成本 |

行数40-60、列数10-14为宜——有实操感又不压垮课堂。

### 第2步 数据架构（四层表，不做大宽表）

```
明细表（事实：发生了什么）     —— 项目×月份×指标
同期表（去年：练跨表同比）     —— 只给关键列，故意分离
台账表（率计算：应收/实收）    —— 模拟真实企业"经营系统vs收费系统"分离
参数表（假设：会怎样变化）     —— 财务建模四件套的输入
```

原则：明细表回答"发生了什么"，参数表回答"利润怎么形成"。**硬塞进一张宽表会把事实和假设搅浑。**

### 第3步 数据生成与埋点

用 `scripts/gen_dataset_template.py` 为骨架生成，三类埋点缺一不可：

1. **结构假象**（核心反转）：公司整体同比≈+1%达成率≈98%看似平稳，实际两极分化（明星+12% vs 问题项目-14%）——教"平均数会说谎"
2. **单点异常**：2-3个，z-score>2，含1个"好的异常"（大单）教"异常不一定是坏事"
3. **趋势问题**：问题项目连续5-6个月环比下滑（达成率递减法，跌幅要>噪声）+ 能耗/客诉系统性超标

项目人设化：标杆/稳健/失速/问题 四种性格，参数见 `references/design-principles.md`。

### 第4步 双版本交付

- **学生版**：明细表 + 同期表 + 台账表 + 参数表 + 实操任务卡（任务编号0-N，只给任务不给答案）
- **老师版**：学生版全部 + 埋点与参考答案 + 指标速查（MoM/YoY全表）+ 教学动线（含示范Prompt）
- Excel生成走 Python openpyxl；样式：深绿表头+边框+冻结首行+列宽

### 第5步 教学包装

每个任务固定五件套（结构模板见 `references/teaching-package.md`）：

```
【用哪张表】【一步一步操作】【预期答案】【讲解稿台词】【坑与救场】
```

- 讲解稿设计反转节奏：先让学员得出"整体平稳"，最后亲手推翻
- 坑即教材：故意让学员踩（文本月份排序、率求和、百分比格式），踩完再讲，记忆最深
- 附救场预案：工具卡壳切AI Prompt路径、进度分层加赛题、时间不够砍什么保什么
