# 学员问卷设计

本工作流只做学员问卷，不另建甲方负责人卷，不把两种角色的问题合并。客户名称用于表单标题和数据隔离，问题询问学员个人情况。

当前顺序：姓名 → 所在部门 → 其他部门补充（条件显示） → 有行为标准的AI自评 → 优先任务 → 真实任务 → 资料状态 → 操作步骤/SOP → 优秀标的物 → 可选附件 → 使用限制 → 设备与软件条件。

11项常规题目及1项条件补充题不加人工序号，由飞书自动编号。姓名是否必填每次新建问卷都问用户；本次已说明则直接采用，不设跨项目默认值。姓名不进入公开报告，不因空姓名排除答卷，也不只按同名去重。

## 说明与问法

说明只保留数据和资料保密、标的物/输入资料定义、勿提交密码和证件号等敏感个人信息三点。

- 部门沿用成熟标准卷分类，必须有“其他”。选择后显示必填文本题“请填写您的部门”，其他情况下隐藏，不能只提供不可填写的“其他”选项。
- AI自评按实际完成过的最高操作选择：未使用、简单问答/写作、调整提示词完成成果、稳定复用提示词、模板或Skill、搭建并测试助手/自动化工作流。它是自评，不等于实际操作验证。
- 设备条件多选，包含Windows、Mac、麒麟、统信/其他Linux、手机/平板、可安装或禁止安装客户端、浏览器网页、内网/指定软件、未知、其他。未知单选；矛盾组合分析时标记并核对。
- 真实任务简短覆盖任务/难点、当前步骤和耗时、输入资料、期望成果及完成标准。使用限制单独收集，不清楚可写待确认；不要求学员代公司授权。

## 材料复用

标的物是优秀成品，输入资料是待加工原材料，两者分开。已有材料引用位置，附件不重复上传；没有样例可填暂无，不捏造优秀成品。共用材料从已有沟通资料复用，只补关键缺口，不另外发送负责人问卷。

“愿意提供”“链接存在”“已读取”“获准使用”分别记录。问卷答案不构成账号操作、文件修改、系统写回或对外发布的执行授权。
