# 博AI课前调研与分析

为每个客户／班次创建独立的飞书学员问卷，回收后形成可向甲方汇报的学员情况分析，使用归藏PPT制作演示稿，并按授权发送邮件与飞书通知。

## 使用

- 创建问卷：“帮我给某客户做一个课前调研。”
- 分析交付：“分析这份问卷，生成甲方汇报版并发到我的邮箱。”
- 调整问卷：“这次姓名选填，部门需要包含其他及补充说明。”

每次新建明确客户名称、姓名是否必填；首次使用询问报告邮箱，之后沿用本机本人设置。问卷由学员填写，不另收业务负责人问卷。

## 安装与依赖

下载并保留本目录的完整结构，包括 `SKILL.md`、`agents/`、`references/`、`templates/` 和 `scripts/`，放入支持 `SKILL.md` 的 Agent 宿主技能目录；不要只复制一个入口文件。宿主是否自动发现技能，以该宿主的实际规则为准。

- Python 3.9+：本地准备与统计脚本仅使用标准库。
- 飞书：已授权的 `lark-cli` 及 `lark-base`、`lark-shared`；通知使用 `lark-im` 或等效授权能力。
- 演示稿：[归藏PPT Skill](https://github.com/op7418/guizang-ppt-skill)，默认沿用使用者确认的风格。
- 邮件：已连接且支持附件的邮箱工具，或已授权的 `agently-mail`。

安装不会自动获得飞书或邮箱权限。邮箱、年度数据库坐标、通知对象保存在包外 `~/.config/boai-questionnaire/profile.json`，不包含授权令牌，也没有作者邮箱默认值。

## 分析与交付标准

完整答卷 → 学员画像与3–5个核心判断 → 归藏PPT → 手机／电脑双端HTML检查 → 直接邮件附件 → 已启用的飞书通知。

每页结论直接说明学员状态、具体差距或应用约束，并解释证据、业务含义与培训重点。细节越充分，分析越具体；客观评价能力、任务、流程和条件，不批评甲方。区分自评、实测、推断与建议，不以问卷选项统计代替学员分析。

电脑版支持横向演示与讲述备注，手机版用于纵向阅读。两份HTML直接发送，不默认打压缩包；原始答卷和客户原件不作为邮件附件。用户说“只出草稿”或“先别发”时以该要求为准。

每年复用使用者指定的飞书数据库，客户／班次独立子表；旧项目保持原坐标。飞书通知支持打开问卷和数据链接，聊天消息自动启动建卷需要另外接通消息处理服务。

## 验证与边界

- 本地行为测试：`python tests/test_workflow.py`，覆盖客户隔离、年度路由、条件题分母、异常选项、模拟数据隔离等27项检查。
- 已完成一次模拟答卷 → 归藏双端HTML → 邮件 → 飞书通知的实际链路验证；模拟数据不代表真实学员或教学成效。
- 真实分析默认排除登记的模拟记录。明确测试项目可使用 `analyze --simulation-only`，结果独立存放。
- `scripts/workflow.py`只做本地准备、配置与统计；云端建卷、专业分析、PPT制作和发送由 Agent 按技能流程调用相应能力完成。

具体规则从 [SKILL.md](SKILL.md) 开始读取。
