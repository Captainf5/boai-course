# 博AI讲课录音复盘

从授课录音或逐字稿定位课程和篇章，校对课程价值观，交付有来源锚点的复盘、案例卡与改课建议。

## 安装与使用

把完整目录交给Agent：“请安装 https://github.com/Captainf5/boai-course/tree/main/boai-recording-review ，帮我复盘这门课。”建议同时安装同合集的boai-course-value。

首次选择手动文件或API来源；手动逐字稿无需API Key。使用Get笔记等API时需操作者自己的账号与安全授权入口，本包不附作者账号或密码。不要把密码发到聊天。

## 兼容性与依赖

文本流程需要文件读取能力；只读适配脚本使用Python 3，按`references/source-workflow.md`调用。音视频转写依赖宿主实际可用的转写能力，本Skill不自带转写引擎。其他录音API必须依据其官方文档适配。

## 数据与适用边界

原始录音、逐字稿及个人配置留在包外。API读取指定来源；额外转写服务上传需得到授权。只复盘教学，不承担通用会议纪要或销售通话分析；没有学员作品时不推断掌握率。

## 验证与故障处理

运行`python -m unittest discover -s tests -v`检查8项只读适配用例。真实来源读取与这些离线测试分别验收；授权失效、分页不完整或转写缺失时保留进度并说明范围，不补造记录。
