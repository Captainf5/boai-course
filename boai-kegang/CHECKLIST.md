# 课纲交付检查

## 内容与表达
- [ ] H1符合主Skill格式且时长准确；无裸标题/旧式连字符；OPC精确例外已核对。
- [ ] 已从13份当前课程包选择最接近的一份成稿基线，并读过语言标杆；只有缺少特定场景时才补读一份历史母版。
- [ ] 定制课不写内部沟通内容：无对接反馈、调研原声引用、定制过程说明；默认Type B结构。
- [ ] 定制课讲解要点第一句锚定"以XX业务线XX案例为场景"，一句话说清，无设计思路解释、无"引入——"式冗长铺垫。
- [ ] 演示是具体案例过程（箭头串联的工作链路），不是"功能走查"类抽象说法。
- [ ] 定制课全文密度紧凑：无重复标题信息、无堆叠解释；总长不超同类基线课纲。
- [ ] 客户能从模块标题、演示与产出看懂课程价值，不是泛泛的功能清单。
- [ ] 每个教学模块（含加餐）先列关键词，再写讲解要点、演示、学员练习、产出物；没有为了“一行”删掉场景与过程。
- [ ] 保留有用的动词、例子和递进关系，没有把口播钩子写成全部课纲。
- [ ] 当前用户要求优先；旧参考内的讲师数字、课程时间、产品功能没有未经核验迁移。
- [ ] 没有新增未经核实的认证、好评率、排名、效果数字和售后承诺。
- [ ] 客户正文不含内部方法论名、修订号、状态、更新时间、待确认清单和净授课分钟数；产品标题可保留已确认的6X方向后缀。
- [ ] 自有课程名称与COURSE-CATALOG一致；标题时长与实际课程说明相符，OPC按独立名称处理；没有用改名掩盖正文缺失。
- [ ] 定制课案例按"嵌入模块"设计（先讲案例后实操同类素材），无独立案例导入段；Day2承接Day1场景不引入新场景。
- [ ] 定制课需客户提供数据时，培训准备含"案例数据样例表头表"与"场景需求描述模板"（5要素），权限清单只列实际需开通项。

## 教学与Agent
- [ ] 先有业务任务和成果样例，再上手；不是先用大量课时配置工具。
- [ ] 交办任务包含结果、材料、边界、验收。
- [ ] 至少有样例对照、修改稿规则提炼、换材料复测。
- [ ] 提示词统一用PCR（Prompt/Context/Right），Prompt讲全“正反合”三招（正向结构化、逆向反推法、逆向结构化）；Right没有省成“做好一点”，旧稿的OC已改写不留两套框架名。
- [ ] WorkBuddy主线的课，模块1是“AI基础认知＋WorkBuddy导入”（大模型、Token、上下文、幻觉＋跑通第一个任务），不是工具选型块；选型只在课程说明用一句结论对齐。
- [ ] 讲解要点≤110字、演示≤80字、学员练习≤80字，单模块四字段合计≤300字（核心模块≤350字）；改旧稿时这三项已压减40%，删的是修饰与解释，事实、数字、文件名与验收点仍在。
- [ ] 岗位AI工作台或成果包围绕真实任务，不硬凑Skill、连接器或偏好条数；一天与两天的任务体量分别设计。
- [ ] 权限、备份、资料指令边界和基础安全进入必修；高级部署与复杂接入分层。
- [ ] 幻觉核验有真实练习，重要数据或结论能回到来源；不把AI自检等同验证。
- [ ] 可编辑文件或可运行成果实际可用，不用截图替代。
- [ ] 视频等不稳定生成有备用成果；定时任务创建与持续运行分开验收。

## 时间
- [ ] 按天分区；总览按天分表，仅“时间／课程内容／课堂成果”三列。
- [ ] 时间表只写上课，区间无重叠；相邻章节有15分钟间隔，午休/下课不重复追加。
- [ ] 模块标注分钟数若出现，与起止区间一致；一天的结束时间正确。
- [ ] 大PK按组数控制展示时间，生成与排错保留缓冲。

## 版式与交付
- [ ] 标题：H1、MD/Word/PDF文件名（`_带图`除外）、Word首页和Title属性一致；客户名仅在文件夹。
- [ ] 原始 Word 可直接打开，不依赖“打开并修复”或二次保存。
- [ ] 使用标杆的橙色标题体系、微软雅黑、清晰层级、讲师与现场图片，不自换卡片风。
- [ ] 多日课程用醒目的日级分隔带区分，不以默认强制分页制造空白；客户明确要求每日起页时才单独处理。
- [ ] 课程大纲、课程产出、课件展示、课程现场、课后准备与培训准备自然顺排。
- [ ] 标题不孤悬页尾；没有因手工分页、整段保持或整章同页而出现只有一两行文字的大面积空白页。
- [ ] 表格能换行、表头重复、行不拆页，图片不拉伸且说明不孤立。
- [ ] Word和MD内容一致；PDF/固定预览逐页检查，无乱码、溢出、纯空白页或非必要低利用率页面。
- [ ] 同一PDF在手机、电脑页序一致；不把响应式阅读当固定版式。
- [ ] 推送仅含授权内容，无凭据、个人数据或无关改动。
- [ ] 无远程运行证据，不称“已推送”或“移动流程已跑通”。
- [ ] 更新后，13份索引、手机包与ZIP均同源且哈希一致。
- [ ] 手机默认只加载核心规则包与一个方向包；组合未超过工程字符预算，附件未读到或被截断时明确停止，不把不完整读取冒充同等质量。
- [ ] 写稿不依赖Codex专用工具名、作者绝对路径或本机Word；桌面与手机都按同一结构、时间、事实、安全和视觉清单验收。
- [ ] 区分包兼容性、文件安装、客户端发现和真实调用；手机附件实际未加载时不冒充已经读完。
