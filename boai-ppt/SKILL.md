# 博AI教学PPT

本入口保留两套已有制作方式；两套设计约定不同，不把它们同时执行，也不按版本号自动覆盖。

1. 用户明确选择实现时沿用；否则WorkBuddy使用[WorkBuddy实现](variants/workbuddy/INSTRUCTIONS.md)，Codex使用[Codex实现](variants/codex/INSTRUCTIONS.md)。其他宿主默认使用Codex实现的通用制作流程，并核对当前演示文稿和图像工具。
2. 实际制作前完整读取所选实现。其内部资源路径以该实现所在目录为根，例如Codex实现的`assets/`指`variants/codex/assets/`。
3. WorkBuddy实现优先使用slidep；缺工具时按其回退路径执行。Codex实现使用宿主可用的演示文稿工具。没有制作能力时只交逐页脚本，明确未完成PPT。
4. 先读取材料、区分大纲与制作请求；明确授权后持续完成制作、渲染核对和交付，不重复审批同一事项。
5. 真实素材、账号和工具由使用者提供；安装本Skill不包含登录授权或付费服务。不上传未经授权的客户材料，不改写原文件。

两套实现的来源、依赖和未验证范围见[使用说明](README.md)。公开包只提供当前所需的参考图与规则，不携带本机绝对路径或旧整套课件。
