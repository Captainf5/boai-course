## 2. 版式骨架（1280×720）

- **左侧红色竖条**：`position:absolute; left:0; top:0; width:10; height:720; background:#E8443A`

- **右侧竖排英文**："Embrace AI, Empower U"
  - 普通页：`left:1020, top:345, width:260, whiteSpace:'nowrap', textAlign:'center', transform:'rotate(90deg)', fontSize:13, color:#E8443A, letterSpacing:2`
  - **1160 宽内容页（商务咨询页，内容到 x=1220）**：用 `left:1180, top:345, width:100`——旋转后文字带中心移到 x≈1230，不遮挡正文（2026-10-08 用户反馈修订）
  - 红底章节页：color 改 `rgba(255,255,255,0.7)` 或 `#FFFFFF`
  - 关键：nowrap + 盒子整体在画布内（left+width≤1280）
- **页脚**：`博AI · Agent时代工作坊`，左下或右下，fontSize:11-12，灰 `#9CA3AF`
- **无页码**——任何地方都不出现

## 3. 字体

**字体三件套（手写 XML / 排查乱码必看）**：中文文本框必须同时设 `latin` + `ea`（东亚）+ `cs`（复杂文种）三个 typeface，且都指向中文字体（思源黑体 Source Han Sans SC / 微软雅黑 Microsoft YaHei）——只设 latin，中文会变方框□或问号。英文/数字可用 Inter 风格无衬线。DSL 默认栈 `'Source Han Sans SC','思源黑体',sans-serif` 已处理；手写 XML 要自己补 `<a:ea typeface="Microsoft YaHei"/>` 与 `<a:cs typeface="Microsoft YaHei"/>`。

**字号下限（2026-10-19 用户指令：核心观点 12–14 号以上，减少小字解释）**：
- 核心观点/主标题：≥14pt（fontSize ≥18.67px，建议 19–27px）
- 正文/要点：≥12pt（fontSize ≥16px）
- 注释/二级解释：能删则删；必须保留的 ≥11pt（≥14.67px），且一页不超过 2 行小字
- 原则：宁可删掉一段小字，不堆 10pt 以下解释——突出核心文字，减少细碎说明
- 换算：sz(pt×100) = fontSize(px) × 75，即 14pt ≈ 18.67px、12pt = 16px、11pt ≈ 14.67px

正文 15–16px（≈11–12pt），卡片标题 19–20px（≈14–15pt），行高 1.5–1.6。

## 4. 五种页型（出课纲前让用户逐页点选）

| 页型 | 用途 | 特征 |
|---|---|---|
| **A 模板内容页** | 常规知识点 | DSL 绘制：卡片/表格/阶梯/金字塔，白底红强调 |
| **B 卡通小人·信息图插画风**（默认推荐） | 关键概念页 | ImageGen 全幅插图：讲师IP小人+流程图+一句话理解卡+底部金句横幅，详见 cartoon-page.md |
| **C 巨字金句高潮页** | 每章1个视觉高潮 | 全红反白 或 三色巨字（如 OCR 页），纯文字冲击 |
| **D 截图证据页** | 社会证明 | 推文/产品UI/新闻截图，加红色描边框+一句点评 |
| **E 章节页** | 章节分隔 | 全红底+白色巨字章节号+白竖排英文 |

节奏建议：每章 1 个 C 类高潮页；关键概念（3-5 个/课）用 B 类；实操对比/数据用 A 类表格。

## 5. 内容原则

- 每页带"判断/所以呢"落点，不做信息板
- 标题是观点不是名词（如"软件是软件，模型是模型"）
- 表格 > 列表 > 段落
- **突出核心、删细碎解释**（2026-10-19 用户指令）：一页只留一个核心观点，能一句话说清的不用三句；二级解释、注释性小字能删就删，不因"排版困难"硬塞 10pt 以下文字——字号下限见 §3
- **方法论页必带"提示词案例条"**（2026-10-08 用户要求）：浅黄底 `#FEF3D9` 横条 + 粗体"提示词案例："（`#B45309`）+ 可直接复制使用的提示词原文（引号包裹，落到学员真实业务场景）。位置：底部红横幅上方，height 44-48。
- **连续多页禁同版式**（2026-10-13 用户批评"模板这么少"后立规）：同一批新页中，相邻页不得复用同一种内容版式。版式轮换池：灰卡矩阵/斑马纹表格/左右对照/流水线(顶红条卡+→箭头)/文档mock(红头文件+✓行)/阶梯/金字塔/巨字金句/截图证据。选版式先看内容结构（并列→矩阵、流程→流水线、清单→文档mock、对比→左右对照），再看上一页用过什么。
