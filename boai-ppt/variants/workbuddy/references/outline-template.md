# 极简逐页Markdown约定（环节一）

供环节一生成大纲、环节二读取脚本使用。五项足够：标题写在页标题行，不另增重复字段。金句非必需；画面写具体元素与关系；人物无则写"无"，有则写动作。用户已有类似字段时直接兼容，不要求重新填表。

## 五项格式

```markdown
## P1｜页面标题
- 内容：
  - 要点一
  - 要点二
  - 要点三
- 画面：一句话说明布局、元素及其关系。
- 金句：一句结论，或"无"。
- 人物：无／有，注明人物动作。
```

文件开头写课程名称、听众、时长、学习目标，随后逐页输出。

## 可复制提示词（给用户共创时用）

```text
请根据以下课纲，生成一份完整的40～50页PPT逐页脚本，以一个Markdown文件交付，供 boai-ppt Skill 制作。

1. 先组织教学逻辑，再分页；每页承担一个主要任务。
2. 每页只写五项：标题、内容、画面、金句、人物。
3. 内容是实际放上PPT的文字，通常3～5个要点；保留关键步骤、判断标准和案例，不写长段口播。
4. 画面用一句话说明布局与关系，例如流程、对比、表格、截图或手绘场景，不只写"美观、专业"。
5. 金句仅在必要时使用，没有就写"无"。
6. 严谨图解为主，人物只用于关键概念解释，默认建议不超过总页数20%，避免连续出现；已有用户约定优先。
7. 不编造数据、案例效果或来源；缺失材料标"待补充"，模拟数据明确标注。
8. 一次输出全部页面，不省略、不用"同上"占位。

文件开头写课程名称、听众、时长、学习目标，随后逐页输出五项格式。

以下是课纲：
【粘贴课纲】
```

40～50页是用户常用批量需求，不是所有课程的固定长度。时长、目标和页数存在明显冲突时提具体建议，不擅自扩页。若用户要共创，先解决影响主线的缺口，再完整输出；"一次输出"不等于忽略必要澄清。

## 与 slidep 制作的衔接

逐页脚本确认后进入环节二：B/C 类页（概念页）先走 cartoon-page.md 生图，A/D/E 类页直接写 DSL。画面字段即 DSL 构图或 ImageGen prompt 的场景描述来源；金句字段 = 底部浅红底金句横幅文案；人物字段 = 概念页 BOBO 动作设计依据。
