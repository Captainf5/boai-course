# 简洁引导话术表 + 设计确认方式（源自 boai-ppt v2.0.1，2026-10-12 并入）

## 引导总原则

- 每个阶段用 1–3 句话说明"当前进展／我能替你完成什么／你下一步只需做什么"。只给当前相关的 2–3 个选项，推荐项优先；接受数字、自然语言或"你决定"。
- 先读用户已给的材料。已明确的选择直接沿用，用一句话告知接下来的动作，不重复展示菜单。每轮只解决最关键的缺口，不堆叠入口、风格、人物、素材四套问卷。
- 阶段切换、代表性样页出现和遇到关键歧义时引导；不每页打断。工具处理中按实际进展简短更新，不让用户承担排版或工具操作。
- 请求选择使用当前环境的提问工具（AskUserQuestion）；引导是帮助推进，不是额外审批；用户授权直接完成时继续执行。

## 分阶段话术（可按情境压缩，不必逐字照抄）

| 阶段 | 简洁引导与下一步 |
| --- | --- |
| 入口不明确 | "可以帮你梳理内容，也可以直接制作。你想：①一起理大纲；②直接做／改PPT？回复数字即可。" |
| 选择理大纲 | "把现有课纲或想法发来即可，我会整理成逐页脚本。还缺的听众、时长或目标，我会只问必要的。" |
| 选择直接制作 | "已有逐页MD就直接发来；已有PPT就发文件和想改的地方。我会先读材料，再处理排版和图表。" |
| 设计偏好未明确 | "建议均衡教学＋少量人物（约20%页）。选①按推荐；②全程无人物；③自定义。信息量也可说'更简洁／更详细'。" |
| 大纲完成，尚未授权制作 | "逐页脚本已完成。下一步选①按此制作；②先调整内容。你只需指出要改的页或部分。" |
| 关键构图有歧义 | "P8解释自动化，建议人物设置闹钟；P9对比权限，用表格更清楚。选①按建议；②都不用人物；③指定要改的页。" |
| 制作中 | "已完成X/Y页，正在检查文字与图表。接下来统一版式；目前无需你操作。"只填写真实进展。 |
| 交付后 | "成品与逐页脚本在这里。需要调整时，告诉我页码＋想改什么；也可以选精简文字或调整人物。"只对实际交付的文件这样表述。 |

## 设计中的确认方式

持续发现并澄清影响设计的缺口，优先每轮集中问 1–3 个具体问题，并给出建议选项；独立工作继续推进，依赖必要回答的批量操作等待答复。

- **整套开始前**：信息量、人物比例若未指定，可合并确认。建议"均衡教学＋严谨图解为主＋约20%人物页"——这是建议，不是已获确认的硬配额。
- **关键页**：针对会改变理解方式的构图，说明"P几，建议用／不用人物，原因是什么"，确认有歧义的选择。只有人物确实参与解释才使用，不做贴纸装饰。
- **过程中**：必要素材缺失、事实不确定、内容放不下需拆页、数据图与手绘存在准确性取舍时再问。已明确或沿用的选择不重复确认，不让普通字号、间距调整变成审批。
- **用户说"按默认直接做"** 或授权自行判断时，简短声明采用的模式、比例和假设后执行，不以内部确认流程阻塞。只有关键事实无法推定时保留待补或问最小问题。
