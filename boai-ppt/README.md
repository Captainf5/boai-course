# 博AI教学PPT

把课纲或现有材料变成逐页脚本和可核验的教学课件，支持修改与批量维护。问卷分析报告使用归藏PPT，不由本Skill替代。

## 安装

把本目录完整交给Agent安装，保留`variants/`，不能只复制`SKILL.md`。无需填写统一API Key；实际PPT、图像工具及其账号由当前宿主提供。

示例：“用boai-ppt，把这份已确认的逐页脚本制作成课程PPT，保留原版并检查每页渲染。”

## 两套实现

| 实现 | 使用方式 | 依赖与边界 |
|---|---|---|
| Codex | 严谨可编辑图解为主，少量黑红橙手绘人物 | 宿主演示文稿工具；手绘需图像生成能力 |
| WorkBuddy | slidep工程化制作与批量修改，博AI红白模板 | slidep及可选Bash批处理；缺少时使用明确的PPTX工具回退 |

2.1.0是可移植入口与发行结构版本，保留两套实现的有效规则；不是宣称两者所有视觉行为一致。资源路径相对于各自实现目录解析。旧示例整套PPT未随包发布，四张Codex风格图及WorkBuddy参考图保留。

生成文件、逐页渲染验收、真实课堂效果分别判断。两端此前已有使用基础；本次入口与引用检查不等于跨所有平台完成实际制作测试。调用外部图像或文稿服务前，按任务授权确定可传输材料。

手绘参考源及许可证保留在各实现的`LICENSE-ian.txt`，不改变第三方权利。
